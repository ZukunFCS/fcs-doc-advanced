 Using FCS with AI Agents (MCP)

Starting with FCS 26.10, FCS can provide a local Model Context Protocol (MCP) server. An MCP-compatible AI agent can inspect the current FCS session, operate supported workflows, and read the bundled FCS operating guide.
AI agents can directly help you the time consuming part of your tasks. 

## Before You Start

You need:

- FCS 26.10 or later with a valid license, running on the same computer as the AI agent.
- An MCP client that supports Streamable HTTP servers on the local computer.

FCS must remain open and licensed while the agent is working on it. The MCP server listens only on `127.0.0.1`, so it is not available to other computers or to cloud-only agents.

## Enable the MCP Server

1. Launch FCS normally. The procedure is the same for the installed FCS
  executable and for a Python/script launch.
2. Open **Settings** and expand **MCP Server**.
3. Enable **Enable MCP Server**.
4. Keep the default port, `19877`, unless it conflicts with another local
  program.
5. Save the settings.
6. Confirm that the status displays **Listening at
  [http://127.0.0.1:19877/mcp](http://127.0.0.1:19877/mcp)**.

Use the complete URL shown by FCS when configuring a client. If you change
the port, use the updated URL in every client configuration. Port `19876` is
reserved by FCS and cannot be used for MCP.

## Connect an AI Agent

The setup is performed once for each agent. Name the server `fcs` or `FCS`
and use the URL displayed in FCS.

### ChatGPT Desktop and the Codex App

1. Open **Settings > Plugins > MCP**.
2. Select **Add server**.
3. Enter `FCS` as the name and select **Streamable HTTP**.
4. Enter `http://127.0.0.1:19877/mcp` as the URL.
5. Save the server and restart the app when prompted.

This applies to local ChatGPT/Codex clients that support custom MCP servers.
ChatGPT in a web browser cannot connect directly to the FCS loopback address.

### Codex CLI

Run:

```powershell
codex mcp add fcs --url http://127.0.0.1:19877/mcp
```

Use `codex mcp list` to check the connection. Inside Codex, use `/mcp` to view
the connected server and its tools.

### Claude Code

Run:

```powershell
claude mcp add --transport http --scope user fcs http://127.0.0.1:19877/mcp
```

The user scope makes FCS available in future Claude Code sessions on this
computer. Run `claude mcp list` to check the connection.

### Visual Studio Code and GitHub Copilot

1. Open the Command Palette with **Ctrl+Shift+P**.
2. Run **MCP: Add Server**.
3. Select **HTTP**, enter the FCS URL, and name the server `FCS`.
4. Choose the global/user profile location so that the connection is available
  outside one workspace.
5. Open Chat and use **Configure Tools** to confirm that the FCS tools are
  available.



### OpenCode

Add a remote MCP server to the OpenCode configuration:

```json
{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "fcs": {
        "type": "remote",
        "url": "http://127.0.0.1:19877/mcp",
        "oauth": false
      }
    }
  }
}
```

FCS does not require OAuth because the endpoint is restricted to the local
computer. Check the MCP server list in OpenCode after saving the configuration.

### Claude Desktop

Claude Desktop custom connectors are intended for remotely reachable servers
and cannot be assumed to reach FCS at `127.0.0.1`. FCS currently does
not ship the separate stdio bridge required by Claude Desktop's traditional
local MCP configuration. Use Claude Code or another local Streamable HTTP
client instead.

## Available Workflows

The public MCP tools cover these areas:

- Application and session status checks, session creation, opening, inspection, and
saving.
- Video importing and selection, along with browsing video libraries.
- Single and batch processing, including job status checks, progress monitoring, and cancellation.
- Session exporting, export path validation, and retrieval of default export settings.
- DCC integration, including status checks, connection testing, launching, and scene opening.
- Processing profiles and application settings, including checks and updates.
- Profile / Gallery operations, including searching and filtering, updating, predicting, and deleting, alongside timeline navigation.
- Controller management, including data retrieval, editing, reordering, preset application, renderer synchronization, and
explicit saving.

FCS intentionally exposes a curated set of named tools. License management and
internal application commands are not available through MCP. The exact tool
list is discovered automatically by the client when it connects.

## Review Actions Before Approval

Your MCP client may request approval before a tool runs. Read the proposed
action carefully, particularly before allowing an agent to:

- Delete ROMs or cancel processing jobs.
- Change and save application settings.
- Save a session or controller table.
- Start processing or export files.

Prefer asking the agent to inspect or validate first, summarize the planned
changes, and perform the mutation only after you approve it. Controller edits
remain a working draft until the agent explicitly saves them.

## Troubleshooting



### FCS shows Disabled

Enable **MCP Server** in Settings and save. Merely changing the checkbox without
saving does not apply the setting.

### FCS shows Waiting for a valid license

Complete FCS license activation. The endpoint starts only while the license is
valid.

### FCS shows an error or the port is already in use

Choose another port from `1024` through `65535`, except `19876`, save the
settings, and update the URL in the AI agent.

### The agent cannot connect

Confirm that FCS is still open, its status says **Listening**, and the
client URL exactly matches the status URL, including `/mcp`. A client running
on another computer, in a remote development environment, or only in the cloud
cannot reach the FCS `127.0.0.1` endpoint.

### The agent connects but an action is rejected

Check that the FCS license is still valid. The requested operation may also be
outside the curated public tool set or may require an open session, selected
video, renderer connection, or other FCS state. Ask the agent to inspect
the application and session status before retrying.
