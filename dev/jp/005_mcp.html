FCSをAIアシスタントと使用する（MCP）

FCS 26.10以降では、FCSからローカルのModel Context Protocol（MCP）サーバーを利用できます。MCP対応のAIアシスタントは、現在のFCSセッションを確認し、対応するワークフローを操作し、同梱のFCS操作ガイドを読むことができます。AIアシスタントは、時間のかかる作業を直接支援できます。

開始する前に

必要なもの：

  • 有効なライセンスが設定され、AIアシスタントと同じコンピューターで実行中のFCS 26.10以降。

  • ローカルコンピューター上のStreamable HTTPサーバーに対応するMCPクライアント。

アシスタントがFCSで作業している間は、FCSを起動したままにし、有効なライセンスを維持する必要があります。MCPサーバーは127.0.0.1でのみ待ち受けるため、別のコンピューターやクラウド専用のアシスタントからは利用できません。

MCPサーバーを有効にする

  1. 通常どおりFCSを起動します。インストールされたFCS実行ファイルから起動する場合も、Python／スクリプトから起動する場合も手順は同じです。

  2. Settingsを開き、MCP Serverを展開します。

  3. Enable MCP Serverを有効にします。

  4. 他のローカルプログラムと競合しない限り、既定のポート19877を使用します。

  5. 設定を保存します。

  6. ステータスにListening at http://127.0.0.1:19877/mcpと表示されることを確認します。

クライアントを設定するときは、FCSに表示された完全なURLを使用します。ポートを変更した場合は、すべてのクライアント設定で変更後のURLを使用してください。ポート19876はFCSによって予約されているため、MCPには使用できません。

AIアシスタントを接続する

設定はアシスタントごとに一度だけ行います。サーバー名をfcsまたはFCSとし、FCSに表示されたURLを使用します。

ChatGPTデスクトップとCodexアプリ

  1. Settings > Plugins > MCPを開きます。

  2. Add serverを選択します。

  3. 名前にFCSと入力し、Streamable HTTPを選択します。

  4. URLにhttp://127.0.0.1:19877/mcpと入力します。

  5. サーバーを保存し、指示が表示された場合はアプリを再起動します。

この手順は、カスタムMCPサーバーに対応するローカルのChatGPT／Codexクライアント向けです。Webブラウザー版のChatGPTは、FCSのループバックアドレスへ直接接続できません。

Codex CLI

次のコマンドを実行します：

codex mcp add fcs --url http://127.0.0.1:19877/mcp

codex mcp listで接続を確認します。Codex内では/mcpを使用して、接続済みサーバーとそのツールを表示できます。

Claude Code

次のコマンドを実行します：

claude mcp add --transport http --scope user fcs http://127.0.0.1:19877/mcp

ユーザースコープに設定すると、このコンピューター上の今後のClaude CodeセッションでもFCSを利用できます。claude mcp listで接続を確認します。

Visual Studio CodeとGitHub Copilot

  1. Ctrl+Shift+Pでコマンドパレットを開きます。

  2. MCP: Add Serverを実行します。

  3. HTTPを選択し、FCSのURLを入力して、サーバー名をFCSにします。

  4. 1つのワークスペース以外でも接続を利用できるように、グローバル／ユーザープロファイルの保存先を選択します。

  5. Chatを開き、Configure ToolsでFCSツールが利用可能であることを確認します。

OpenCode

OpenCodeの設定にリモートMCPサーバーを追加します：

{
  "$schema": "https://opencode.ai/config.json",
  "mcp": {
    "servers": {
      "fcs": {
        "type": "remote",
        "url": "http://127.0.0.1:19877/mcp",
        "oauth": false
      }
    }
  }
}

エンドポイントがローカルコンピューターに限定されているため、FCSではOAuthは不要です。設定を保存した後、OpenCodeのMCPサーバー一覧を確認します。

Claude Desktop

Claude Desktopのカスタムコネクターは、リモートから到達可能なサーバーを対象としており、127.0.0.1上のFCSへ接続できるとは限りません。現在のFCSには、Claude Desktopの従来のローカルMCP設定で必要となる個別のstdioブリッジは含まれていません。代わりにClaude Codeまたは別のローカルStreamable HTTPクライアントを使用してください。

FCSに作業を依頼する

接続後は、通常どおりアシスタントに話しかけます。MCPツール名を覚える必要はありません。例：

  • 「FCSに、開いているセッションを確認して要約してもらってください。」

  • 「現在のセッションにある動画を一覧表示し、それぞれの処理状態を示してください。」

  • 「選択中の動画を現在のFCS設定で処理し、完了するまで進捗を報告してください。」

  • 「現在のセッションをエクスポート用に検証し、エクスポート前に問題点を説明してください。」

  • 「現在のコントローラーテーブルを表示して標準プリセットを適用してください。ただし、まだ保存しないでください。」

  • 「FCS操作ガイドを読み、ROMの編集方法を説明してください。」

アシスタントはFCSがMCP経由で公開するガイドを読めるため、操作前にFCS固有の手順を確認できます。

利用可能なワークフロー

公開MCPツールは次の領域に対応しています：

  • アプリケーションとセッションの状態、セッションの作成、オープン、確認、保存。

  • 動画のインポート、ライブラリとシーケンスの参照、動画の選択。

  • 単体処理とバッチ処理、ジョブの進捗、状態、キャンセル。

  • エクスポートの検証、既定値、セッションのエクスポート。

  • レンダラーの状態、接続テスト、起動、シーンのオープン。

  • 処理プロファイルと設定の確認または更新。

  • ROMギャラリーの照会、更新、予測、削除、タイムライン操作。

  • コントローラーの確認、編集、プリセット、並べ替え、同期、明示的な保存。

FCSは、選定された名前付きツールのみを意図的に公開しています。ライセンス管理やアプリケーションの内部コマンドはMCPから利用できません。正確なツール一覧は、接続時にクライアントが自動的に検出します。

承認前に操作内容を確認する

ツールの実行前に、MCPクライアントから承認を求められる場合があります。特に、アシスタントに次の操作を許可する前は、提案された内容を注意深く確認してください：

  • ROMを削除する、または処理ジョブをキャンセルする。

  • アプリケーション設定を変更して保存する。

  • セッションまたはコントローラーテーブルを保存する。

  • 処理を開始する、またはファイルをエクスポートする。

まず確認または検証を行い、予定している変更を要約するようアシスタントに依頼し、承認後にのみ変更を実行させることを推奨します。コントローラーの編集内容は、アシスタントが明示的に保存するまで作業中のドラフトとして保持されます。

トラブルシューティング

FCSにDisabledと表示される

SettingsでMCP Serverを有効にして保存します。チェックボックスを変更しただけでは設定は適用されません。

FCSにWaiting for a valid licenseと表示される

FCSのライセンス認証を完了してください。エンドポイントはライセンスが有効な間だけ起動します。

FCSにエラーが表示される、またはポートが使用中である

19876を除く1024から65535の別のポートを選択して設定を保存し、AIアシスタントのURLを更新します。

アシスタントが接続できない

FCSが起動中で、ステータスにListeningと表示され、クライアントのURLが/mcpを含めてステータスのURLと完全に一致していることを確認します。別のコンピューター、リモート開発環境、またはクラウドのみで動作するクライアントは、FCSの127.0.0.1エンドポイントに到達できません。

アシスタントは接続できるが操作が拒否される

FCSライセンスが引き続き有効であることを確認します。要求した操作が公開ツールの対象外であるか、開いているセッション、選択中の動画、レンダラー接続、その他のFCS状態を必要としている場合もあります。再試行する前に、アプリケーションとセッションの状態を確認するようアシスタントに依頼してください。
